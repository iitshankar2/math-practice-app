# MOEMS Practice App

Static Elementary (Division E) practice + review UI backed by a structured problem bank.

## Files
- `index.html` — kids practice app (text-only / figures / all; source filter)
- `review.html` — searchable bank review with filters
- `moemsBank.js` — **559** problems (contests, tournaments, MAMTS, user practice, samples)

## Use
Keep these files in one folder and open `index.html` or `review.html` in a browser
(or serve the folder with any static server). `moemsBank.js` must sit next to the HTML.

MAMTS items currently have blank answers and are skipped in practice mode until keyed.
